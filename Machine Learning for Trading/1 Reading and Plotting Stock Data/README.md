# Reading and Plotting Stock Data

## Read CSV

To read the CSV file, use the _read-csv.py_ and the stock data file _AAPL.csv_ (downloaded from [Yahoo data history](https://finance.yahoo.com/quote/AAPL/history)).

### How to run

Requires [uv package manager](https://docs.astral.sh/uv/getting-started/installation/)

1. `cd` into this subdirectory
2. Run `uv sync` to install script dependencies
3. Run `uv run python read-csv.py` to run script
