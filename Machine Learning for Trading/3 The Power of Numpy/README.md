# The Power of Numpy

## Script to practice using Numpy

To see how certain Numpy functions work, use the _numpy-ops.py_.

To compare Numpy's vectorized operations with Python loops, use _timing-python.py_

### How to run (with example)

1. `cd` into this subdirectory
2. Run `uv sync` to install script dependencies
3. Run `uv run numpy-ops.py` to run script
4. Run `uv run timing-python.py` to run script
